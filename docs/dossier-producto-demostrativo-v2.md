# Dossier de producto demostrativo v2.0

## Repaso Final Frances A1 · Kit interactivo

**Autor:** Joel Concepcion Villanueva  
**Version de referencia:** 2.0  
**Tipo de documento:** dossier de presentacion de producto demostrativo  
**Caracter:** recurso personal de portfolio docente, no oficial y sin vinculo institucional directo con ICSE ni con el SCE

## 1. Sintesis

**Repaso Final Frances A1 · Kit interactivo** es un recurso didactico digital gratuito, estatico e instalable, orientado al repaso final de Frances A1 para alumnado adulto en contexto FPE.

La version **2.0** consolida el proyecto como producto demostrativo completo: no lo convierte en plataforma, no incorpora backend y no abre recogida de datos. Su valor esta en mostrar un molde realista, reutilizable y prudente para crear recursos similares en otros idiomas iniciales.

## 2. Problema que atiende

En cursos de idioma inicial para personas adultas es frecuente que el alumnado necesite:

- repasar frases basicas de uso inmediato;
- practicar antes de una situacion oral o escrita;
- orientarse desde el movil sin recorrer paginas largas;
- recibir feedback formativo simple;
- disponer de una evidencia local de practica sin entregar datos personales.

El recurso responde a esa necesidad con una experiencia breve, clara y accesible.

## 3. Propuesta de valor

El proyecto ofrece:

- actividades breves de reconocimiento, asociacion y produccion guiada;
- UX movil refinada con recorrido paso a paso, mapa de bloques y barra inferior;
- modo presentacion para aula;
- informe local de practica, opcional y no oficial;
- estructura preparada para audios locales propios del autor;
- estructura documental para adaptar el molde a otros idiomas;
- experiencia instalable ligera tipo PWA;
- documentacion pedagogica, tecnica y de privacidad.

## 4. Alcance del producto demostrativo

La version 2.0 permite presentar el recurso como:

- evidencia de competencia digital docente;
- herramienta complementaria de repaso para Frances A1;
- ejemplo de diseno instruccional aplicado a alumnado adulto;
- prototipo reutilizable para otros idiomas iniciales;
- base de conversacion con entidades formativas, sin presentarlo como producto oficial.

No debe presentarse como:

- recurso oficial de ICSE;
- recurso oficial del Servicio Canario de Empleo;
- herramienta validada institucionalmente;
- plataforma de evaluacion;
- sistema de seguimiento del alumnado.

## 5. Principios de diseno

La version 2.0 mantiene estos criterios:

- claridad antes que decoracion;
- tono adulto, funcional y no infantilizado;
- una idea principal por pantalla en movil;
- minima friccion tecnica;
- uso sin cuentas;
- ausencia de datos personales;
- compatibilidad con GitHub Pages;
- posibilidad de instalacion ligera en navegadores compatibles;
- documentacion suficiente para replicar el modelo.

## 6. Privacidad y seguridad

El recurso:

- no tiene backend;
- no tiene login;
- no usa analitica;
- no usa formularios externos;
- no incorpora IA/API;
- no envia respuestas a servidores externos;
- no recoge datos personales;
- guarda el progreso solo en el navegador mediante `localStorage`.

En el reto final se recomienda usar un nombre de pila o ficticio. No deben introducirse apellidos, DNI, telefono, correo, direccion ni datos sensibles.

## 7. Componentes del paquete v2.0

El paquete demostrativo queda formado por:

- `index.html`: recurso interactivo principal;
- `manifest.webmanifest` y `sw.js`: experiencia instalable ligera;
- `assets/capturas/`: evidencia visual de escritorio, movil y modo presentacion;
- `assets/lang/`: inventario de contenidos y plantilla de paquete linguistico;
- `assets/audio/`: estructura preparada para audios locales propios del autor;
- `docs/`: memoria, ficha pedagogica, guias de aula, UX, PWA, validacion, adaptacion y roadmap;
- `LICENSE.md`: criterios de licencia para codigo y contenidos.

## 8. Uso en una presentacion profesional

Una presentacion breve puede seguir esta secuencia:

1. Explicar que es un recurso complementario y personal de portfolio docente.
2. Mostrar la portada y el recorrido guiado movil.
3. Enseñar una actividad breve y el mapa de bloques.
4. Activar el modo presentacion para aula.
5. Mostrar el informe local como evidencia formativa no oficial.
6. Explicar privacidad: sin backend, sin login y sin recogida de datos personales.
7. Cerrar con la idea de molde reutilizable para otros idiomas iniciales.

## 9. Encaje prudente con FPE y Canarias

La formulacion recomendada es:

> Recurso didactico digital gratuito, creado por Joel Concepcion Villanueva, orientado al repaso de Frances A1 para alumnado adulto en contexto FPE. Funciona como herramienta complementaria y evidencia de competencia digital docente. A largo plazo, puede servir como molde adaptable a otros idiomas y contextos de formacion para el empleo, sin presentarse como recurso oficial ni sustituir materiales o evaluacion institucional.

## 10. Cierre v2.0

La version **2.0** se considera un cierre demostrativo suficiente para portfolio: el recurso es publicable, instalable, documentado, prudente en privacidad y preparado para explicar su posible adaptacion sin prometer validacion institucional.
