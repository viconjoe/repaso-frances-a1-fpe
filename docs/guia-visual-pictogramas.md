# Guía visual de pictogramas

## Repaso Final Francés A1 · Kit interactivo

**Autor:** Joel Concepción Villanueva  
**Versión de referencia:** 1.0  
**Tipo de documento:** apoyo visual local del recurso  
**Carácter:** recurso complementario, no oficial y sin vínculo institucional directo con ICSE ni con el SCE

## 1. Finalidad

La versión 0.8 incorpora pictogramas SVG propios para reforzar la orientación visual del recurso sin añadir dependencias externas.

Los pictogramas no sustituyen las instrucciones escritas. Funcionan como apoyo visual para alumnado adulto, especialmente en tareas de repaso rápido, uso autónomo o proyección en aula.

## 2. Pictogramas incluidos

Los archivos están ubicados en `assets/pictogramas/`:

- `comprender.svg`: apoyo para reconocimiento y comprensión de frases.
- `responder.svg`: apoyo para selección de respuestas comunicativas.
- `practicar.svg`: apoyo para producción guiada y práctica escrita/oral.
- `evidencia.svg`: apoyo para informe local y evidencia orientativa.
- `privacidad.svg`: recordatorio visual de protección de datos.

## 3. Criterios de diseño

Los pictogramas se han diseñado con:

- formas simples;
- colores coherentes con la interfaz;
- contraste suficiente para uso general;
- estilo sobrio, no infantilizado;
- archivos SVG locales y editables;
- ausencia de librerías, iconos externos o servicios de terceros.

## 4. Uso pedagógico

Los pictogramas ayudan a reforzar la secuencia didáctica:

1. Comprender.
2. Responder.
3. Practicar.
4. Guardar evidencia local, si procede.

También refuerzan la privacidad antes del reto final, recordando que el alumnado no debe introducir apellidos, DNI, teléfono, correo, dirección completa ni otros datos personales.

## 5. Límites

Los pictogramas son un apoyo visual básico. No constituyen una adaptación completa para accesibilidad cognitiva ni sustituyen una revisión profesional de accesibilidad.

Si el recurso se usa en aula, la persona docente puede complementar los pictogramas con explicación oral, ejemplos y práctica guiada.
