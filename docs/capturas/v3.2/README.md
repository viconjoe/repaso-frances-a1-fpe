**Uso:** evidencia visual de portfolio y documentacion del cierre tras feedback docente.

## Criterio de seleccion

La seleccion combina capturas de movil y ordenador para mostrar dos planos del recurso:

- **Movil:** experiencia principal del alumnado, recorrido guiado, progreso fijo, respuesta a preguntas, practica oral e informe.
- **Ordenador:** vision completa de estructura, navegacion, bloques amplios, ficha docente y rubrica.

No se incluyen datos reales de alumnado. Las capturas son demostrativas y corresponden al despliegue publico de GitHub Pages.

## Uso recomendado en portfolio

Para una presentacion breve, usar 6-8 capturas: inicio, autoevaluacion con feedback, flashcards, audio local, grabacion opcional, informe y ficha docente.

Para una memoria completa, usar la seleccion completa de movil y ordenador.
