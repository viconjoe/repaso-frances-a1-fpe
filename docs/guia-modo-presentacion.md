# Guía de modo presentación

## Repaso Final Francés A1 · Kit interactivo

**Autor:** Joel Concepción Villanueva  
**Versión de referencia:** 1.0  
**Tipo de documento:** uso del modo presentación para aula  
**Carácter:** recurso complementario, no oficial y sin vínculo institucional directo con ICSE ni con el SCE

## 1. Finalidad

El modo presentación está pensado para proyectar el recurso en aula con una visualización más amplia y limpia.

No cambia las actividades ni convierte el recurso en una herramienta de evaluación. Solo adapta la presentación visual para facilitar explicación, práctica guiada y trabajo grupal.

## 2. Cómo activarlo

Desde la portada del recurso:

1. Pulsar **Modo presentación**.
2. Usar la navegación del recurso para moverse por bloques.
3. Pulsar **Salir de presentación** para volver al modo normal.

También se puede salir pulsando la tecla `Escape`.

## 3. Uso recomendado

El modo presentación puede usarse para:

- explicar el objetivo de la sesión;
- resolver el autodiagnóstico con el grupo;
- proyectar flashcards y practicar pronunciación;
- hacer mini-situaciones oralmente;
- explicar el reto final;
- recordar las pautas de privacidad antes de escribir.

## 4. Privacidad

Aunque se use en proyección, deben mantenerse las mismas pautas:

- no escribir apellidos;
- no escribir DNI;
- no escribir teléfono;
- no escribir correo electrónico;
- no escribir dirección completa;
- usar nombre de pila o nombre ficticio en el reto final.

## 5. Límites

El modo presentación no registra resultados, no envía datos, no usa backend y no incorpora analítica.

Si se proyecta en aula, conviene evitar que se muestren producciones personales del alumnado salvo que sean ejemplos ficticios o estén autorizados y anonimizados.
