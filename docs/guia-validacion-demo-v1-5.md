## 3. Validación técnica realizada

Comprobaciones realizadas en local:

- `index.html` carga sin errores JavaScript;
- la versión visible indica `1.5`;
- el informe local usa versión `1.5`;
- el modo guiado móvil se activa;
- no hay desbordamiento horizontal en móvil;
- `manifest.webmanifest` es válido;
- el manifest declara 3 iconos;
- el service worker se registra en servidor local `http`;
- la PWA conserva el enfoque sin backend, login, analítica, formularios externos, IA/API ni solicitud o transmisión de datos personales.

## 4. Checklist antes de presentar

Antes de enseñar el recurso en portfolio o aula:

- abrir la URL publicada en GitHub Pages;
- comprobar que carga la versión actual;
- probar el recorrido guiado en móvil;
- probar **Ver todos los bloques**;
- probar el selector **Ir a...**;
- comprobar el modo presentación en escritorio o proyector;
- comprobar si el navegador ofrece **Instalar app** o **Añadir a pantalla de inicio**;
- recordar que el recurso es complementario y no oficial;
- no introducir apellidos, DNI, teléfono, correo ni datos sensibles en el reto final.

## 5. Guion breve de demo

Duración sugerida: 60-90 segundos.

### 0-10 segundos

Presentar el recurso:

> Este es un recurso digital complementario de repaso de Francés A1 para alumnado adulto. Es una herramienta personal de portfolio docente, no oficial y sin solicitud o transmisión de datos personales.

### 10-25 segundos

Mostrar la portada móvil:

> La versión actual prioriza la experiencia móvil: cabecera breve, información en desplegables y recorrido guiado por bloques.

### 25-45 segundos

Mostrar actividades:

> El alumnado puede hacer un autodiagnóstico orientativo, repasar flashcards, emparejar frases con intenciones y resolver mini-situaciones comunicativas.

### 45-60 segundos

Mostrar privacidad e informe:

> El reto final recomienda usar nombre de pila o ficticio. El informe es local, orientativo y no se envía a ningún servidor.

### 60-75 segundos

Mostrar instalación:

> También puede instalarse como PWA ligera desde navegadores compatibles, manteniendo el funcionamiento estático y sin login.

### 75-90 segundos

Cierre:

> La finalidad es ofrecer un molde gratuito, prudente y adaptable para otros idiomas iniciales, sin sustituir la programación docente ni la evaluación oficial.
